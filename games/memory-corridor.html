HOW TO PLAY · 游戏规则
目标：探索回廊、收集记忆碎片，并找到出口。
移动：使用 WASD / 方向键。灰黑色区域是墙，空白区域可以通行。
探索：每进入一个新房间都会记录路线；你的访问顺序会改变部分剧情。
物品：靠近黄色方块即可自动拾取。钥匙、照片、录音带分别会改变后续记忆。
出口：到达绿色边框的位置会触发结局判断。不同物品组合 + 探索程度对应不同结局。
声音：第一次点击“声音”或游戏画面后，浏览器才允许播放 Web Audio。移动、拾取和文字出现时都会有声音。
