想把自己的小游戏放上来？
把你写的单文件 .html 丢进仓库的 games/ 目录，提个 Pull Request 就行。 合并后会自动上线，无需改动这个导航页。
📥 参与贡献
怎么贡献一个小游戏？
  1. Fork 仓库，把 games/_template.html 复制一份改名（比如 games/my-game.html），照着写你的游戏。
  2. 页面必须是单文件、零依赖（样式和脚本内联，不要引用外部 js/css；图片音频请用 CDN 绝对地址或内联 data URI）。
  3. 在 <head> 里写好 <title>、meta charset、meta viewport，再按需加 wb-category / wb-icon / wb-author 等标签。
  4. 提 Pull Request。机器会自动校验，通过后由维护者合并 —— 合并后你的游戏会出现在这个页面上。
